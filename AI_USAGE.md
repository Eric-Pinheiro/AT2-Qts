# Relatório de Transparência de IA
- **Ferramenta Utilizada:** Google Gemini.
- **Uso:** Geração do esqueleto do projeto, configuração de fixtures com Faker e estruturação do Page Object Model (POM) para Playwright.
- **Auditoria:** Todo o código gerado foi revisado manualmente e testado localmente via `uv run pytest` para garantir a cobertura dos cenários de sucesso e falha estipulados no PRD.
